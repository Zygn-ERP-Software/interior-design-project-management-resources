# Interior Design Project Management Resources

A practical collection of checklists, workflows, templates, and resources for managing interior design projects.

Interior design projects involve multiple activities, including client communication, design planning, BOQ preparation, estimation, procurement, execution, task management, billing, and project handover.

This repository organizes useful resources around those activities.

## What's Included

### 1. Project Planning

Resources for organizing an interior project before execution begins.

Typical activities include:

* Project scope definition
* Requirement collection
* Project timeline planning
* Task assignment
* Team coordination
* Milestone planning
* Client communication

### 2. BOQ & Estimation

A structured BOQ helps interior design teams document materials, quantities, specifications, and estimated costs.

A typical BOQ can include:

| Item      | Description       | Quantity | Unit    | Rate | Estimated Amount |
| --------- | ----------------- | -------: | ------- | ---: | ---------------: |
| Flooring  | Flooring material |      500 | Sq. Ft. |    — |                — |
| Lighting  | Light fixtures    |       20 | Nos.    |    — |                — |
| Furniture | Custom furniture  |        5 | Nos.    |    — |                — |
| Paint     | Interior painting |     1200 | Sq. Ft. |    — |                — |

The exact structure should be adapted to the requirements of each project.

### 3. Procurement

Procurement resources can help teams track:

* Material requirements
* Supplier information
* Purchase requests
* Purchase orders
* Expected delivery dates
* Received quantities
* Pending materials
* Procurement status

### 4. Task Management

An interior project can be divided into stages such as:

1. Enquiry
2. Client consultation
3. Site measurement
4. Concept development
5. Design approval
6. BOQ and estimation
7. Procurement
8. Execution
9. Quality checks
10. Handover

Breaking a project into manageable tasks makes responsibilities and progress easier to track.

### 5. Client Communication

Useful client communication records may include:

* Requirements
* Design discussions
* Material selections
* Design approvals
* Estimate approvals
* Change requests
* Project updates
* Handover communication

Maintaining these records can help teams keep project communication organized.

### 6. Project Cost Tracking

Project teams can monitor:

* Estimated project cost
* Material costs
* Purchase costs
* Labour costs
* Additional expenses
* Client billing
* Outstanding amounts
* Project profitability
